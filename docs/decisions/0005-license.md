# 0005: License

- Status: Accepted
- Date: 2026-10-27

## Context

The GitHub repo is public. Engineers may want to learn from or reuse the code, but the site's
content is Karthik's personal identity.

## Options

1. **MIT for code, content all rights reserved**: open code, protected identity.
2. **All rights reserved**: the code is visible but can't be reused. Most protective, less friendly to
   engineers.
3. **MIT for everything**: simplest, but allows reuse of bio text and images.

## Decision

Option 1. See `LICENSE`. Code is MIT. Written content, personal information (including the
resume), images and branding are all rights reserved.

## Why

An open-source code license reads as generous and confident to engineers. Reserving the content
means nobody can clone the site wholesale and pass off Karthik's story or images as their own.
