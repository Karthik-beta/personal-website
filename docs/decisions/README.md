# Decision records

Each file records one decision Karthik approved, so future work (and future sessions) stay
consistent. Keep them short.

- File name: `NNNN-short-slug.md`, numbered in order.
- Never rewrite an accepted decision. To change one, add a new ADR and mark the old one
  `Superseded by NNNN`.

## Template

```markdown
# NNNN: Title

- Status: Accepted | Superseded by NNNN
- Date: YYYY-MM-DD

## Context

What problem or question prompted this.

## Options

1. Option A: trade-offs
2. Option B: trade-offs

## Decision

What we chose.

## Why

The reasoning, in plain language.
```
